** Plan (ema's reply)
Four small steps, each as its own suggestion:

1. Per-run counter: beside the conversation total =ema--usage=, keep a
   per-run total that resets at each sent message; =ema--add-usage=
   (ema.el) adds to both.
2. Price: a =defcustom ema-prices= (model regexp -> per-million price
   for input / cached read / cache write / output) and a function that
   computes $ from the usage.  For Anthropic, split the cache writes
   out of =:in= in =ema--anthropic-parse= (ema-llm.el), since they cost
   more.
3. Status bar: =ema-mode-line= shows only while busy now.  Make it
   always show e.g. =ema ↑35k ⚡716k ↓11k $4.10 (run $0.31)=, plus the
   spinner when busy; the chat header shows the same.
4. Optional fix: the OpenAI parser always reports =:cached 0=; read
   =usage.prompt_tokens_details.cached_tokens=, and for OpenRouter
   =usage.cost= (the real price).

cache write, output per Mtok) — the user fills them in; until then
